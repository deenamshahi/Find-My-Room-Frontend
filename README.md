**🏠 Find My Room — Frontend**

Find My Room is a mobile application frontend built with React Native that helps users easily find and manage rental rooms and flats. This repository contains only the frontend part of the application.

**📱 Features**

📍 View current location
🏘️ Display list of properties added by the user
🖼️ View property images, prices, availability, and locations
📦 Responsive UI with a clean and modern design
🧭 Navigation-ready (React Navigation)
☁️ Easy integration with backend APIs

**🛠 Tech Stack**
React Native
Expo
React Navigation
JavaScript

**🚀 Getting Started**

**Prerequisites**
Node.js ≥ 14
Expo CLI: npm install -g expo-cli
